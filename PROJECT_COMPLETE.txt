## 🔧 BUILD INSTRUCTIONS

### Prerequisites
1. Download Crow header:
   - From: https://github.com/CrowCpp/Crow/releases
   - Save to: `d:\Cpp Project\include\crow_all.h`

2. Install SQLite3 development libraries:
   ```bash
   # Using vcpkg
   vcpkg install sqlite3:x64-windows
   ```

### Build Steps
```bash
cd "d:\Cpp Project"
mkdir build
cd build

# Configure with CMake
cmake -DCMAKE_BUILD_TYPE=Release ..

# Build
cmake --build . --config Release
```

### Run Server
```bash
Release\server.exe
```

### Access Application
- URL: http://localhost:8080
- Test Customer: rajesh_kumar / customer@2024
- Test Manager: shripad_deshpande / staff@2024
